Seus dados

O que você digita fica com você

Nada é enviado para a internet. O kit guarda um rascunho automático neste navegador, mas esse rascunho pode se perder se o histórico for apagado ou se você abrir o arquivo em outro computador.

Para guardar com segurança, use Exportar dados: você recebe um arquivo .json com tudo o que foi preenchido. Depois, use Importar dados para continuar de onde parou.

Orientações finais

Antes de usar as informações

  • Confira os dados antes do uso

    Compare as informações registradas com os documentos e com os responsáveis por cada etapa antes de lançar dados em qualquer sistema.

  • Adapte os campos à sua empresa

    Use os campos de observação e as linhas adicionais para incluir o que for próprio dos seus procedimentos internos.

  • Guarde cópias de forma organizada

    Salve os PDFs e os arquivos de dados com nomes claros, por exemplo F08_2026-10_Unidade-A, conforme a organização interna.

  • Consulte os procedimentos oficiais

    Quando houver dúvida sobre documentos exigidos, prazos ou classificação, siga os procedimentos oficiais e o sistema aplicável.

Apresentação

Formulários prontos para organizar a rotina de resíduos

Este kit reúne 15 formulários para as tarefas que acontecem em volta do MTR: pedir uma coleta, reunir os dados de um resíduo, conferir transportadores e destinadores, preparar as informações antes de lançar no sistema e registrar o que aconteceu depois da saída da carga.

Cada formulário já vem com campos organizados em blocos, espaço para observações e um campo de registro. Você escolhe o modelo, preenche, confere e guarda uma cópia.

Os formulários deste kit são modelos internos de organização e registro. Não substituem documentos oficiais, avaliações técnicas ou procedimentos exigidos pelos órgãos competentes.

Categoria 01Preparação da coleta

Use antes da movimentação: registre o pedido de coleta, organize os dados do resíduo, levante quantidades, confira o acondicionamento e programe a retirada.

Categoria 02Dados e movimentação

Use para cadastrar transportadores e destinadores, reunir os dados que serão lançados no MTR, conferir documentos antes da saída e registrar a retirada.

Categoria 03Acompanhamento operacional

Use depois da saída da carga: registre o recebimento informado, divergências de quantidade, ocorrências, pendências e o encerramento do acompanhamento.

Versão digital

Abra o arquivo HTML no navegador, sem internet. Os campos são preenchíveis, as tabelas aceitam novas linhas e cada formulário pode ser impresso ou salvo em PDF com os dados digitados. Os dados também podem ser exportados e importados em arquivo .json.

Versão impressa

Este PDF traz os 15 formulários em branco, prontos para imprimir e preencher à mão. Ele é um documento para impressão e arquivamento, sem campos digitais.

Como os formulários estão organizados

F08v1.0
Código e versão

Cada modelo tem um código, de F01 a F15, e um campo de registro para a sua numeração interna.

ABC
Blocos de campos

Os campos ficam agrupados em blocos lógicos, na ordem em que as informações costumam aparecer.

ÚnicaVárias
Opções para marcar

Círculos indicam escolha única. Quadrados permitem marcar mais de uma opção. No papel, marque com um X.

CPNA
Siglas de conferência

C = Conferido · P = Pendente · NA = Não aplicável. Em acondicionamento: V = Verificado · NC = Necessita conferência.

Campos em branco

Deixe em branco o que ainda não foi informado e registre a pendência no próprio formulário. Isso evita dados presumidos.

Nome dos arquivos

Ao salvar em PDF, use o código do formulário no nome do arquivo. Fica mais fácil localizar depois.

Orientações finais

Antes de usar as informações registradas

  • Confira os dados antes do uso

    Compare as informações registradas com os documentos e com os responsáveis por cada etapa antes de lançar dados em qualquer sistema.

  • Adapte os campos à sua empresa

    Use os campos de observação e as linhas adicionais para incluir o que for próprio dos seus procedimentos internos.

  • Guarde cópias de forma organizada

    Salve os PDFs e os arquivos de dados com nomes claros, por exemplo F08_2026-10_Unidade-A, conforme a organização interna.

  • Consulte os procedimentos oficiais

    Quando houver dúvida sobre documentos exigidos, prazos ou classificação, siga os procedimentos oficiais e o sistema aplicável.

Um complemento para a sua rotina

O Kit Pré-MTR foi pensado para ser usado junto com os 70 Fluxos Visuais de MTR, CDF e Controle de Resíduos. Os fluxos ajudam a entender cada etapa, a planilha de controle acompanha os registros de MTR e CDF, e estes formulários organizam as informações de cada coleta e de cada situação específica.
